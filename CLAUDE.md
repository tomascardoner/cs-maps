## Overview

CS-Maps is a Windows Forms desktop app (.NET 10, `net10.0-windows`, x64) by Cardoner Sistemas for managing geographic points (`Punto`), their data and events, settlements (`Establecimiento`) and entities (`Entidad`), with import/export to Garmin GPS devices (GPX) and Google Earth (KML). UI text, database schema and model names are in Spanish (es-AR); code identifiers outside the models (forms, methods, enums) are in English. There are no tests.

## Build

```powershell
dotnet build CS-Maps.slnx                 # Debug build
.\build\Build.ps1                         # Release publish (single-file, ReadyToRun, framework-dependent) to artifacts\win-x64
```

- **External dependency:** the project references `CardonerSistemas.Framework.*` DLLs via HintPath from a sibling repo at `..\..\cs-framework.net\` (relative to `Desktop application\`). That repo must be built in the matching configuration (Debug/Release) first, or the build fails. Note the reference ItemGroups are conditioned on `Platform == AnyCPU`.
- `EnforceCodeStyleInBuild` is on and `Workleap.DotNet.CodingStandards` analyzers run during build — style violations surface as build warnings/errors. Existing code suppresses specific rules with `#pragma warning disable/restore` (e.g. `MA0048`, `S2223`, `CA1822`); follow that pattern rather than disabling rules globally.
- `Nullable` is disabled; `ImplicitUsings` is enabled. Prefer collection expressions (`[.. query]`) as the existing code does.

## Runtime / startup

`Main/Program.cs` drives startup and holds global state in static fields (`Program.AppearanceConfig`, `DatabaseConfig`, `Parametros`, `Usuario`, `Permisos`, `FormMdi`):

1. Loads JSON config from `<exe dir>\config\` (`Appearance.json`, `Database.json`, `General.json` — sources in `Desktop application/Config/`).
2. Builds the SQL Server connection string; the DB password in `Database.json` is encrypted and decrypted with `Constants.PublicEncryptionPassword`. `Server` may list multiple data sources separated by `;` (user picks one).
3. Loads the `Parametro` table and verifies `ApplicationDatabaseGuid` matches `Constants.ApplicationDatabaseGuid`, then decrypts the licensed company name.
4. When running under the Visual Studio IDE, login is skipped and the admin user (`Constants.UserAdministratorId`) is used; otherwise `FormUserLogin` is shown.

Running the app requires a reachable SQL Server `CSMaps` database.

## Architecture

- **Data access (EF Core, database-first):** `Models/` is generated by **EF Core Power Tools** from the database (config in `Desktop application/efpt.config.json`, fluent API only, DB names preserved). Do not hand-edit generated files (`CSMapsContext.cs`, entity classes, `CSMapsContextProcedures.cs`, `DbContextExtensions.cs`); put customizations in partial-class `*Extension.cs` files (e.g. `CSMapsContextExtension.cs` supplies the static `ConnectionString` and `OnConfiguring`; `PuntoExtension.cs` adds export-only computed properties). The stored procedure `ObtenerPuntosDatosYEventos` lives in `Scripts/`.
- **No DI:** forms do `using Models.CSMapsContext context = new();` directly. Primary keys are `ValueGeneratedNever` — new IDs are computed in code as `Max(id) + 1` (see `FormEntity.cs`, `FormPoint.cs`, etc.).
- **MDI shell:** `Main/FormMdi` is the container. Menu handlers check `Users.Permissions.Verify(Permissions.Actions.X)` and open singleton child forms via `Common.Forms.GetXxxOrNew()`.
- **List/detail form pattern** (`General/`, `Users/`): a plural list form (`FormEntities`) loads all rows, filters/sorts in memory, and binds to a DataGridView; a singular detail form (`FormEntity`) handles view/edit/new with a long-lived `_dbContext`, then calls `Common.RefreshLists.Xxx(id)` to refresh the open list form and reselect the row. DB errors go through `Common.DBErrors`, generic exceptions through `CardonerSistemas.Framework.Base.Error.ProcessException`. When adding a new entity form, mirror an existing pair and wire it into `Common.Forms`, `Common.RefreshLists`, `FormMdi` and `Permissions.Actions`.
- **Permissions:** `Users/Permissions.cs` — the `Actions` enum values map to `Permiso` rows in the database by ID, so new actions need matching DB rows.
- **Import/Export** (`ImportExport/`): GPS uses `MediaDevices` (MTP) or drive scanning to find Garmin `GPX` folders (`CommonFunctions.cs`); Google Earth uses `SharpKml`. UI components use Syncfusion (license key registered in `Program.Main`).
- **Strings and images** are in `Properties/Resources.resx` (`Properties.Resources.StringXxx`, `ImageXxx`).
